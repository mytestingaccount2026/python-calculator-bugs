# Simple Python Calculator

A basic command-line calculator written in Python with various arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power (exponentiation)
- Modulo (remainder)

## Installation

No external dependencies required! Just Python 3.6+

## Usage

Run the calculator:

```bash
python calculator.py
```

Follow the on-screen prompts to select an operation and enter numbers.
